실행 방법
1. ZIP을 원하는 폴더에 압축 해제합니다. 두 소스 폴더의 상대 위치를 유지합니다.
2. Python 3.12를 준비합니다. 첫 실행 시 프로젝트 내부 의존성 다운로드가 필요합니다.
3. Windows: SO101_로컬앱/START_APP.cmd를 실행합니다.
4. 직접 CLI: so101-env-agent 폴더에서 scripts/run_demo.ps1을 PowerShell로 실행합니다.
5. Ubuntu: so101-env-agent 폴더에서 bash scripts/run_demo.sh를 실행합니다.
6. 결과는 생성된 runs 폴더의 JSON·trace·환경 파일로 확인합니다.
